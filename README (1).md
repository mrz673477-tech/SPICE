# 透明 SPICE · 电路分析教学台

一个免费的电路分析教学软件。Windows 用户可以从 GitHub Releases 下载安装包；安装后无需联网即可使用。也可以直接在浏览器中打开 `index.html`，或将本目录部署为静态网站。

## 下载与安装（Windows）

1. 打开本项目 GitHub 仓库的 **Releases** 页面，下载最新版本中的 `透明SPICE-Setup.exe`。
2. 双击安装包。软件安装到当前用户目录，不需要管理员权限；安装完成后可从桌面或开始菜单启动。
3. 如需卸载，可从开始菜单的“透明 SPICE”文件夹选择“卸载 透明 SPICE”，也可通过 Windows 已安装应用列表卸载。

软件免费使用，采用 MIT 开源许可证。首次下载需要联网；安装完成后，电路编辑和分析均在本机运行，支持离线使用。新版本发布后，请回到 Releases 页面手动下载并安装。

> Windows 可能会对未进行代码签名的安装包显示安全提示。请只从本项目 GitHub Releases 下载，并在下载页核对发布者提供的 SHA-256 校验值。当前版本尚未配置代码签名证书。

## 当前实现

- 可在空白画布上自由放置 R、C、L、独立电压源、独立电流源和开关，再用导线连接元件端子。
- 可添加分支接点、移动元件和接点；下方元件表可编辑数值、状态和删除元件。GND 接点固定为参考节点 `0`。
- 直流工作点分析：电容开路，电感和闭合开关按理想短路处理。
- 单频交流相量分析：电容、电感按复导纳建模，独立源按峰值、0° 相位处理；结果显示幅值、相位及节点电压波形。
- 使用改进节点法组装 MNA 矩阵，并用带部分主元的高斯消元求解。
- 展示矩阵方程、节点电压、电压源电流、电阻电流和元件级推导说明。
- 元件值支持基础 SI 后缀，例如 `1k`、`10u`、`2m`；大数可用科学计数法，例如 `1e6`。

## 操作

1. 点击“新建电路”，选择器件并填写参数，再点击“放元件”，最后点击画布空白处放置。
2. 选择“导线”，依次点选两个放大的元件端子，或从起点直接拖到目标端子/接点。拖动时端点会吸附并高亮；按 Esc 取消。要接分支时，先放置接点，再把各支路连到该接点。
3. 元件左端为端子 a；电压源 a 端为正，电流源方向为 a → b。开关状态可在元件表中切换。
4. 点击“运行分析”查看结果；“删除器件”工具可点击删除画布上的元件，并一并清理其端子导线；元件表也提供“删除”按钮。接错导线可点击“撤销导线”。初始示例是 12 V 电源驱动电阻分压器，并带一个并联开关。

放置前先输入纯数字，再从旁边的单位菜单选择单位。R 可选 Ω、kΩ、MΩ；C 可选 F、mF、μF、nF、pF；L 可选 H、mH、μH；V 可选 V、mV、kV；I 可选 A、mA、μA。S 选择初始通/断状态。缺少参数或输入无效时不会放置器件。

## 开发与部署

本项目是纯静态网站，不需要构建步骤或第三方依赖。GitHub Pages 可直接从仓库根目录发布；也可以部署到其他支持静态文件托管的平台。桌面和手机浏览器均可访问。

Windows 桌面安装包由 GitHub Actions 在发布版本标签（例如 `v1.0.0`）时自动构建，并附加到 GitHub Release，同时生成 SHA-256 校验文件。重建安装包请在 Windows 上运行 `powershell -ExecutionPolicy Bypass -File installer/build-installer.ps1`。

## 范围

当前实现直流工作点与单频交流相量分析。暂态分析、符号解，以及网孔法/节点电压法独立求解器尚未实现；方法标签用于教学说明，当前数值求解统一采用 MNA。交流源相位暂按 0°。目标定位为课程演示原型，不替代成熟 SPICE 工具。
